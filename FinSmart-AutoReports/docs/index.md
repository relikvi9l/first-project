# 📊 Автоматизация отправки отчётов | FinSmart Case

## 📌 Описание проекта

Проект реализует автоматическую генерацию и отправку отчётов через e-mail для пользователей сервиса FinSmart. Основная цель — сократить рутину и улучшить доступ к финансовой аналитике.

---

## 🎯 Цель

- Автоматизировать рутинную отправку отчётов
- Упростить жизнь бухгалтерам, собственникам и менеджерам
- Повысить прозрачность бизнес-процессов

---

- Сбор требований

## 📦 Как это работает

1. Пользователь создаёт рассылку
2. Сервер сохраняет задачу на отправку
3. По расписанию формируется отчёт
4. Отчёт уходит пользователю на e-mail
